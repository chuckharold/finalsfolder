PCNL STUDENT INFORMATION SYSTEM - BEGINNER VERSION

This project uses basic HTML, CSS, PHP, and MySQL. The design is simple and suitable for a beginner-level school project.

FEATURES
- Login and logout
- Admin and staff roles
- Dashboard with totals
- Add, view, edit, and search student records
- Admin can delete student records
- Admin can create system user accounts
- MySQL database
- Simple responsive CSS

HOW TO RUN USING XAMPP
1. Install XAMPP.
2. Copy this folder into C:\xampp\htdocs\
3. Start Apache and MySQL.
4. Open http://localhost/phpmyadmin
5. Import database.sql.
6. Open http://localhost/finalsfolder/create_admin.php once.
7. Log in at http://localhost/finalsfolder/login.php

HOSTING NOTE
This project uses PHP and MySQL. GitHub can host the source-code repository, but GitHub Pages does not execute PHP or provide a MySQL database, so the expected GitHub Pages URL will not run this system by itself. To make the system live, deploy the PHP files and database to a PHP/MySQL-compatible host, and use the GitHub URL for the source repository. Update db.php with the database details from the PHP hosting provider.
